# Estatística com Python

Exercícios de estatística descritiva com Python (pandas/numpy), usando uma
base de dados socioeconômicos (UF, sexo, idade, cor, anos de estudo, renda,
altura).

- **`Curso_de_Estatística_Parte_1_ distribuicao_de_requencias.ipynb`** —
  distribuição de frequências.
- **`Exercícios.ipynb`** — exercícios complementares.
- **`Verifica_versão.ipynb`** — checagem de versões das bibliotecas usadas.
- **`dados.csv`** — base de dados usada nos notebooks acima.
