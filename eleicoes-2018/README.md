# Eleições 2018 — votação por seção eleitoral (MG)

Análise exploratória da votação por seção eleitoral nas Eleições 2018 em
Minas Gerais.

- **`Eleições 2018.ipynb`** — notebook com a análise.
- **`leiame.pdf`** — dicionário de dados original do TSE, explicando as
  colunas do arquivo de votação por seção.

O notebook espera o CSV de votação por seção (MG, 2018), que não está
incluído aqui por ser um dataset público grande — baixe direto nos
[Dados Abertos do TSE](https://dadosabertos.tse.jus.br/).
