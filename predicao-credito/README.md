# Predição de crédito

Modelo de predição de aprovação de crédito usando o dataset **Credit Approval** (UCI Machine Learning Repository, também conhecido como "Japanese Credit Screening").

- **`create_model_that_predict_credit_card.ipynb`** — notebook principal: análise exploratória e construção do modelo de classificação.
- **`crx.data`** / **`crx.names`** — dataset original (instâncias e descrição dos atributos).
- **`credit.names`** / **`credit.lisp`** — material de referência adicional sobre o domínio (regras de concessão de crédito).
- **`Untitled.ipynb`** — rascunho exploratório.
