# Datasets diversos para exercícios de ML

Datasets soltos usados como base em exercícios pontuais de Machine Learning
deste repositório — não têm um notebook próprio aqui, servem de matéria-prima
para outros exercícios ou para prática livre.

- **`credit_card.csv`** — dados de uso de cartão de crédito por cliente
  (saldo, compras, limite, pagamentos etc.), usado em exercícios de
  clusterização/segmentação de clientes.
- **`fetal_health.csv`** — indicadores de cardiotocografia fetal, usado em
  exercícios de classificação (saúde fetal: normal, suspeito, patológico).
