# Análise de campanha de marketing

Análise exploratória de uma campanha de marketing, com dados de clientes
(perfil, renda, gastos por categoria de produto) e resposta a campanhas
promocionais anteriores.

- **`marketing_campaing.ipynb`** — notebook com a análise.
- **`marketing_campaign.csv`** / **`marketing_campaign.xlsx`** — base de
  dados usada, em dois formatos.
- **`Arquivo marketing_campaign_Descritivo do conteúdo (1).pdf`** —
  dicionário de dados original, explicando cada coluna.
