# Leitura de arquivos com pandas e Spark

Exercícios de leitura de diferentes formatos de arquivo, comparando pandas e
Spark.

- **`LEITURA_ARQUIVO_CSV_PANDAS_DADOS_EXAMES.ipynb`** — leitura de CSV com pandas (dados de exames).
- **`LEITURA_ARQUIVO_JSON_PANDAS_DADOS_ESTUDANTES.ipynb`** — leitura de JSON com pandas (dados de estudantes).
- **`LEITURA_ARQUIVO_JSON_SPARK_DADOS_ESTUDANTES.ipynb`** — leitura de JSON com Spark (dados de estudantes).
- **`LEITURA_ARQUIVO_PARQUET_SPARK_DADOS_VOOS.ipynb`** — leitura de Parquet com Spark (dados de voos).
- **`LEITURA_ARQUIVO_XML_SPARK_DADOS_ALUNOS.ipynb`** — leitura de XML com Spark (dados de alunos).
- **`LEITURA_ARQUIVO_XML_SPARK_DADOS_BANCARIOS.ipynb`** — leitura de XML com Spark (dados bancários).
